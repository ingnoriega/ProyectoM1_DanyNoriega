# Documentación del uso de Inteligencia Artificial

## Herramienta utilizada

ChatGPT — OpenAI.

## Objetivo

Utilizar inteligencia artificial como apoyo para aprender JavaScript, organizar el proyecto, comprender las funcionalidades y revisar buenas prácticas.

## Registro de prompts

| Prompt utilizado                                                                               | Resultado obtenido                                                                               |
| ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| "Ayúdame a organizar un proyecto de generador de paletas de colores para mi curso Full Stack." | Propuesta de estructura, funcionalidades y etapas de desarrollo.                                 |
| "Revisa que no hayan ambigüedades y que funcione de buena manera."                             | Revisión del CSS e identificación de selectores repetidos.                                       |
| "Next" (continuación del desarrollo)                                                           | Explicaciones progresivas de generación HEX, HSL, renderizado dinámico, eventos y accesibilidad. |

## Evidencias

Agregar capturas de las conversaciones con ChatGPT y de los resultados aplicados al proyecto.

## Reflexión sobre el uso de IA

La inteligencia artificial se utilizó como una herramienta de aprendizaje y acompañamiento. Permitió comprender conceptos de JavaScript, organizar las etapas del proyecto y recibir recomendaciones para mejorar el código.

Las funcionalidades deben verificarse mediante pruebas realizadas en el navegador.
